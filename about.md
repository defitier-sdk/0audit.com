WebAudit Lab (`0audit.com`) is a free, zero-account website diagnostics platform built on an **Evidence-Before-Scores** methodology. Instead of opaque 0–100 vanity scores, it inspects live HTTP responses, response headers, and raw HTML markup to report exact observed values, why each signal matters, and explicit verification boundaries.

### 6 Free Diagnostic Tools
1. **Technical SEO Audit** ([/tools/seo-audit/](https://0audit.com/tools/seo-audit/)) — HTTP status & redirect chains, indexability (`robots` meta & `X-Robots-Tag`), title/description quality, H1–H6 outline, keyword consistency, text-to-HTML ratio, canonicals, `hreflang` alternates, internal links, in-page sitemap discovery, and JSON-LD presence.
2. **Website Performance Audit** ([/tools/performance-audit/](https://0audit.com/tools/performance-audit/)) — Server fetch latency (TTFB), HTTP compression (gzip/Brotli), Cache-Control directives, HTML transfer size (<150 KB budget), inline script/style minification heuristics, synchronous render-blocking scripts, stylesheet load, DOM complexity, and image lazy-loading. Explicitly separates server delivery from field Core Web Vitals (CrUX LCP/INP/CLS).
3. **HTML Code Quality Audit** ([/tools/code-audit/](https://0audit.com/tools/code-audit/)) — HTML5 doctype, document `lang`, semantic landmarks (`<main>`, `<nav>`, `<header>`, `<footer>`), mobile touch target spacing, icon ecosystem (ICO, Apple touch icon, SVG favicon), OpenGraph & Twitter social cards, missing image `alt` attributes, duplicate DOM IDs, unlabeled form controls, and inline event handlers.
4. **AI Search Readiness Checker** ([/tools/ai-search-readiness/](https://0audit.com/tools/ai-search-readiness/)) — Crawlability for AI retrieval bots, extractable prose volume, sequential heading structure, entity definition opening passage, concise answer blocks, Q&A heading-to-answer structure density, Schema.org entity types, authorship, publication dates, external source citations, and fact & data density.
5. **Structured Data Checker** ([/tools/structured-data-checker/](https://0audit.com/tools/structured-data-checker/)) — JSON-LD syntax validation, detected Schema.org entity types, Google Rich Snippet mandatory field requirements (Article, WebApplication, Product, Organization, FAQPage), and visible-content parity checks (preventing hidden FAQ or unverified rating claims).
6. **Security Headers Checker** ([/tools/security-headers-checker/](https://0audit.com/tools/security-headers-checker/)) — HTTPS enforcement, `Strict-Transport-Security` (HSTS), `Content-Security-Policy` (CSP), clickjacking protection (`frame-ancestors` / `X-Frame-Options`), `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Permissions-Policy`, cross-origin isolation (`COOP` / `COEP` / `CORP`), server technology and software version leakage detection, and mixed content subresource detection.
