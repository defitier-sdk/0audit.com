WebAudit Lab (`0audit.com`) is a free, zero-account website diagnostics platform built on an **Evidence-Before-Scores** methodology. Instead of opaque 0–100 vanity scores, it inspects live HTTP responses, response headers, and raw HTML markup to report exact observed values, why each signal matters, and explicit verification boundaries.

### 6 Free Diagnostic Tools
1. **Technical SEO Audit** ([/tools/seo-audit/](https://0audit.com/tools/seo-audit/)) — HTTP status & redirect chains, indexability (`robots` meta & `X-Robots-Tag`), title/description quality, H1–H6 outline, canonicals, `hreflang` alternates, internal links, and JSON-LD presence.
2. **Website Performance Audit** ([/tools/performance-audit/](https://0audit.com/tools/performance-audit/)) — Server fetch latency (TTFB), HTML transfer size (<150 KB budget), synchronous render-blocking scripts, stylesheet load, DOM complexity, and image lazy-loading. Explicitly separates server delivery from field Core Web Vitals (CrUX LCP/INP/CLS).
3. **HTML Code Quality Audit** ([/tools/code-audit/](https://0audit.com/tools/code-audit/)) — HTML5 doctype, document `lang`, semantic landmarks (`<main>`, `<nav>`, `<header>`, `<footer>`), missing image `alt` attributes, duplicate DOM IDs, unlabeled form controls, and inline event handlers.
4. **AI Search Readiness Checker** ([/tools/ai-search-readiness/](https://0audit.com/tools/ai-search-readiness/)) — Crawlability for AI retrieval bots, extractable prose volume, sequential heading structure, concise answer blocks, Schema.org entity types, authorship, publication dates, and external source citations.
5. **Structured Data Checker** ([/tools/structured-data-checker/](https://0audit.com/tools/structured-data-checker/)) — JSON-LD syntax validation, detected Schema.org entity types, and visible-content parity checks (preventing hidden FAQ or unverified rating claims).
6. **Security Headers Checker** ([/tools/security-headers-checker/](https://0audit.com/tools/security-headers-checker/)) — HTTPS enforcement, `Strict-Transport-Security` (HSTS), `Content-Security-Policy` (CSP), clickjacking protection (`frame-ancestors` / `X-Frame-Options`), `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Permissions-Policy`, and cross-origin isolation (`COOP` / `COEP` / `CORP`).

### Key Capabilities
- **100% Free & No Registration**: Instant browser-based diagnostics with zero signup or paywall.
- **12 Localized Languages**: Full native interface and localized audit reports in English (`/`), German (`/de/`), French (`/fr/`), Spanish (`/es/`), Italian (`/it/`), Portuguese (`/pt/`), Dutch (`/nl/`), Polish (`/pl/`), Ukrainian (`/uk/`), Russian (`/ru/`), Simplified Chinese (`/zh/`), and Japanese (`/ja/`).
